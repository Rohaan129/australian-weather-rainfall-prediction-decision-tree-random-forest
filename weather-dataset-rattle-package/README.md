# Rainfall Prediction in Australia: Decision Trees and Random Forests

## Overview
This project explores whether it will rain tomorrow in Australia using the Kaggle **Rain in Australia (Weather Dataset)**. It uses exploratory data analysis and tree-based machine-learning models, including a Decision Tree Classifier and a Random Forest Classifier.

The target variable is `RainTomorrow` (`Yes` or `No`).

## Project goals
- Explore weather patterns and relationships with next-day rainfall.
- Prepare numerical and categorical weather features for machine learning.
- Train and compare Decision Tree and Random Forest classifiers.
- Investigate overfitting and tune model hyperparameters.
- Examine class weighting because rainy days are less common than non-rainy days.
- Save a trained Random Forest model with Joblib.

## Dataset
Download `weatherAUS.csv` from the Kaggle dataset:
[Rain in Australia — Weather Dataset](https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattle-package)

Place the downloaded CSV in a local `data/` directory, for example:

```text
data/weatherAUS.csv
```

The dataset contains daily observations from Australian weather stations. The notebook predicts `RainTomorrow` from weather observations and related features. The dataset is not included in this repository.

## Notebook
Open `DT-RF.ipynb` in Jupyter Notebook, JupyterLab, or Visual Studio Code and run the cells in order.

**Important:** Update the CSV path in the notebook to match your local dataset location. Avoid hard-coding a personal absolute Windows path if you plan to share or run the notebook on another machine.

## Models and experiments
The notebook covers:
- Exploratory analysis of the target distribution and weather features
- Decision Tree training and regularization
- Random Forest experiments with parameters such as `n_estimators`, `max_features`, `max_depth`, and `max_leaf_nodes`
- Experiments with `min_samples_split`, `min_samples_leaf`, bootstrapping, and `class_weight`
- Training and validation evaluation, including a classification report and confusion matrix

The notebook includes experiments with class weighting to improve detection of the minority `RainTomorrow = Yes` class. Accuracy alone can be misleading for this imbalanced target, so precision, recall, F1-score, and the confusion matrix should also be considered.

## Saved model
The notebook saves a Random Forest model as:

```text
rainfall_prediction_model.joblib
```

The saved estimator is the classifier fitted in the final model-saving cell. Make sure the model is trained with the intended hyperparameters and that preprocessing is handled consistently before using it for predictions. The notebook currently performs preprocessing separately, so the saved classifier alone may not include all preprocessing steps.
